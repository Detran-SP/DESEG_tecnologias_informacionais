# Apêndice: Bases Abertas de Dados de Sinistros de Trânsito em 15 Países

## Contexto

Este apêndice integra o artigo "Maturidade informacional comparada de sistemas abertos de dados de sinistros de trânsito: um diagnóstico internacional", submetido ao ANPET 2026. O documento apresenta o levantamento detalhado das 15 bases de dados analisadas, com suas respectivas fichas técnicas e classificação no Índice de Maturidade Informacional (IMI).

## Descrição

Arquivo HTML contendo o catálogo completo das bases avaliadas no estudo. Cada base é apresentada em card individual com:

- Nome e país de origem
- Instituição responsável e fonte dos dados
- Data da análise
- IMI calculado e classificação por dimensão (periodicidade, interatividade, desagregação)
- Link para acesso direto ao portal

O documento está organizado em seções expansíveis por faixa de maturidade (Alto a Muito Baixo), permitindo navegação direta por nível de desempenho.

## Metodologia

O IMI é calculado como média aritmética simples de três dimensões (escala 0-10):

| Dimensão | Critérios |
|----------|-----------|
| Periodicidade | Regularidade e atualização dos dados |
| Interatividade | Formato de disponibilização (estático a painel dinâmico) |
| Desagregação | Granularidade e quantidade de variáveis disponíveis |

Período de coleta: janeiro-fevereiro de 2026.
